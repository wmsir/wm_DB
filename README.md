# wmDB (完美数据库) V2.0 商业版

wmDB 是一款高可用、高安全性的企业级 SQL 审核、自动化流转与数据安全查询平台。

## 核心特性
1. **数据库实例管理与实时连通性测试 (Instance Management & Connection Test)**：
   - **列表操作列一键测试**：实例列表中提供【测试连接】按钮，秒级探测目标数据库网络与账号连通性，即时反馈数据库版本（如 MySQL 8.0.36）与网络握手耗时；
   - **结构化配置 (IP / 端口 / 库名 / 账号 / 密码)**：新建与编辑实例支持结构化输入主机 IP、端口、默认库名及密码，系统自动推导并拼装 JDBC URL；
   - **编辑弹窗内实时测试**：在保存实例前即可直接点击【测试连接】进行实时连通性探测，验证无误后一键提交保存。
2. **彻底解耦**：审批状态机（Flowable）与业务执行引擎（SQL Domain）物理拆分，通过 Webhook 回调事件驱动流转。
3. **可视化审批流全景追踪与分级权限审批**：
   - **全景步骤流转追踪**：工单详情页采用现代化视觉节点卡片与状态指示器（`COMPLETED`、`ACTIVE` 待审核高亮动效、`REJECTED`、`PENDING`）；
   - **节点责任与候选审批人展示**：每个节点清晰标明审批职责及可审批人员（如开发组长、核心 DBA、系统管理员）；
   - **管理员全权特权审批**：系统管理员（`ADMIN`）拥有全流程直接审批与驳回最高特权；其他角色（`DBA`、`DEV_LEAD`）按所在节点权限审核。
4. **三种审批执行决策模式与 DBA 结果反馈闭环**：
   - 🚀 **模式 1：立即流式执行 (IMMEDIATE)**：审批通过后，系统后台通过安全流式引擎立即在目标库执行，自动统计实际影响行数、执行耗时并生成防篡改 SM3 审计日志，流转至 `EXECUTED` 已归档状态；
   - ⏰ **模式 2：定时计划执行 (SCHEDULED)**：审批人可指定执行窗口（如凌晨 02:00），工单进入 `WAITING_EXECUTION` 队列，支持到达窗口执行或由管理员/DBA 一键提前手动触发；
   - 🛠️ **模式 3：转 DBA 工具线下执行 (MANUAL_DBA)**：适用于大表重构等高危变更，审批通过后工单进入 `MANUAL_PROCESSING`，DBA 可一键复制 SQL 在 Navicat/DataGrip 线下执行，执行完毕后在平台录入实际影响行数、耗时与验证备注，提交后自动流转归档；
   - 📊 **执行结果与防篡改报告**：工单执行完成后，界面即时呈现实际影响行数、耗时、执行方式与区块链防篡改哈希审计记录。
5. **独立数据查询控制台 (Data Explorer & SQL Query)**：
   - **左侧数据表浏览器**：支持实例与具体数据库选择，动态实时加载库下全部数据表树（含表注释、预估行数、数据大小）与关键字搜索；
   - **点击表名即查**：点击任意数据表即可自动生成并执行 `SELECT * FROM 表名 LIMIT 50;` 并展示表字段结构（主键/字段类型/允许空/默认值/注释）；
   - **严格只读控制**：仅允许 `SELECT`/`SHOW`/`DESC`/`EXPLAIN`，强制拦截 `INSERT`/`UPDATE`/`DELETE`/`DROP` 等写操作；
   - **安全与导出**：内置 `MaxRows` 截断保护与查询超时，支持一键将数据导出为 CSV 或 JSON 格式。
6. **DML 影响行数注解识别与事务级预执行校验 (Dry Run)**：
   - 支持在 SQL 文本或 `.sql` 附件中通过 `-- 1` 或 `-- 影响行数: 1` 声明预期影响行数。
   - 系统支持在目标指定数据库事务内自动模拟预执行，比对各语句的实际影响行数与预期行数，并在校验完成后强制 `ROLLBACK` 回滚事务，行数不符立即拦截阻断，杜绝误操作。
7. **一键启动与停止脚本**：根目录内置 `start_all.bat`（`一键启动.bat`）与 `stop_all.bat`（`停止服务.bat`），双击即可并行启动前后端并自动调起浏览器。

## 数据库实例管理操作指南

进入实例管理页（[http://localhost:5173/instance-list](http://localhost:5173/instance-list)）：

1. **列表一键测试连接**：
   - 在表格操作列中，点击【测试连接】按钮；
   - 系统即时调用底层 JDBC 探测目标数据库，并在右上角通知弹出数据库产品名称、版本号及网络响应毫秒数。
2. **结构化填写配置与实时测试**：
   - 点击【新增实例】或【编辑】；
   - 选择【结构化填写 (推荐)】模式，分别填写：
     - **数据库主机 / IP**：例如 `rm-uf6abp6renk8g3l2wio.mysql.rds.aliyuncs.com` 或 `127.0.0.1`；
     - **端口**：3306（根据引擎类型智能默认）；
     - **默认数据库名**：例如 `huiqitong_erp`；
     - **数据库账号**：例如 `root`；
     - **连接密码**：输入密码（密码采用国密 SM4 对称加密安全落库）；
   - 点击弹窗左下角【测试连接】按钮，实时查看连接状态与引擎版本；
   - 验证通过后点击【保存修改 / 提交审核】。
